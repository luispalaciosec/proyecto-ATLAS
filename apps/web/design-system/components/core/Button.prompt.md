Filled action button in ATLAS's four variants; use `primary` for the single dominant CTA per view.

```jsx
<Button variant="primary" size="lg">Iniciar conversación →</Button>
<Button variant="secondary">Cancelar</Button>
```

Variants: primary (purple fill), secondary (bordered), tertiary (text-only, purple), danger (red fill). Sizes: sm/md/lg. `icon` accepts any leading node.
