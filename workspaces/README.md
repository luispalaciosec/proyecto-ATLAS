# Atlas Workspaces

Proyectos Atlas funcionales que consumen el Kernel mínimo a través del CLI.

## Workspaces disponibles

| Workspace | Milestone | Descripción |
|-----------|-----------|-------------|
| [`first-atlas-workspace/`](./first-atlas-workspace/) | M1 | Primer proyecto Atlas completo — doctor, compile, run |

## Inicio

```bash
pnpm install
pnpm --filter @atlas/cli build
pnpm --filter @atlas/workspace-first demo
```

Ver [first-atlas-workspace/GETTING_STARTED.md](./first-atlas-workspace/GETTING_STARTED.md).
